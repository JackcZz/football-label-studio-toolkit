# camera4 号码串号核对报告（10000–12000 样本）

> 时间 2026-10-24 · 方法：逐帧把「当前标注」的每个框，按位置（中心点距离 < 3 个百分点）对齐「凉白开原始预测」的同标签框，比较号码；位置一致但号码不同即记为「位置对、号码错」。

## 一、校验方案

1. **位置对齐**：当前标注框 A → 凉白开预测框 P（同 label，取距离最近者）。
2. **号码比对**：若 dist(A,P) < 3 个百分点 且 A.号码 ≠ P.号码，判定为「位置正确、号码错误」（串号）。
3. **方向判定**：以凉白开为原始真值；`当前号→凉白开号` 表示「该框当前写的号 → 应写凉白开的号」。
4. **错误范围定位**：对串号帧取「连续区间」，首帧=错误起点，末帧=错误终点（终点后已恢复一致）。

## 四、错误范围定位方法

1. 在样本 10000–12000 内逐帧比对，得到所有「19→58」帧号。
2. 取连续区间：**首帧 10002 为错误起点**（比用户追查的「10100 附近」更早）。
3. **末帧 10485 为错误终点**（10486 起 58/19 恢复一致）。
4. 区间内的「缺口」（如 10004–10005、10090–10102）多为该帧凉白开暂时未检出或标为无号，不改变整体错误范围。

> 若要把错误范围往前扩到 10000 之外（错误是否早于 10000 起），可同样方法向 <10000 方向扫，直到连续 N 帧无 19→58 不一致为止。
